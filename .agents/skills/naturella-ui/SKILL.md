# Naturella UI

## Processo

1. Leia `AGENTS.md`, `feature_list.json` e o guia do módulo afetado.
2. Trabalhe somente na feature UI ativa e reutilize componentes e tokens existentes.
3. Preserve rotas, responsividade, acessibilidade, `alt` text e links externos.
4. Faça a menor alteração que resolve o comportamento solicitado.
5. Execute `./init.sh` antes de concluir e registre a evidência.

## Restrições

- Não adicione dependências, estado global ou abstrações sem necessidade concreta.
- Não declare uma feature aprovada sem verificação reproduzível.
- Atualize o guia do módulo se a superfície ou o comando de verificação mudar.
